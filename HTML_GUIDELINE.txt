Hyperlinks
Anchor Tags
    <a> Text </a> 
        hyperlinks items with description "Text"
    Websites
    <a href="https://website.com/" target="_blank" title=""> </a>
        href is the link to be opened to
        target allows to open on same page or different page
        title a description that pops up when link is hovered
    Files
    <a href="filepath.html" target="_blank" title=""> </a>
        href is the file to be opened to
    Emails
    <a href="mailto:test@fake.com" target="_blank" title=""> </a>
        href begins process to send email


Images
    <img src="" alt="text" height="" width="">
        src is image that is displayed
        works for png, jpg, gif, etc
        alt is text displayed if image doesn't show
    <a href="" target="_blank" title=""> 
        <img src="" alt="text" height="" width="">
    </a>
        Turns image into a hyperlink
